# সত্যের সন্ধানে সব সময় — নিউজ পোর্টাল

## কী আছে
- সবাই নিউজ জমা দিতে পারবে; জমা দেওয়া নিউজ `pending` থাকবে।
- অ্যাডমিন লগইন করে অনুমোদন, বাতিল বা স্থায়ীভাবে ডিলিট করতে পারবেন।
- গত ৯০ দিনের নিউজের সঙ্গে টেক্সট মিলিয়ে সম্ভাব্য ডুপ্লিকেট/কপি নিউজ আটকে দেয় (৮২% শব্দ-সাদৃশ্য বা হুবহু মিল)।
- SQLite ডাটাবেসে নিউজ ও সেশন রাখা হয়।

## চালানোর নিয়ম
1. Node.js 20 বা তার বেশি ইনস্টল করুন।
2. এই ফোল্ডারে টার্মিনাল খুলে `npm install` চালান।
3. `.env.example` কপি করে `.env` করুন।
4. `.env`-এ `ADMIN_PASSWORD` ও `SESSION_SECRET` অবশ্যই শক্তিশালী নতুন মানে বদলান।
5. `npm start` চালান, তারপর `http://localhost:3000` খুলুন।
6. অ্যাডমিন: `http://localhost:3000/admin/login`।

ডিফল্ট ইউজারনেম `admin`; পাসওয়ার্ড `.env`-এ যেটি দেবেন সেটি। ডিফল্ট পাসওয়ার্ড রেখে কখনো ইন্টারনেটে প্রকাশ করবেন না।

## লাইভ করার আগে জরুরি
- HTTPS সহ Node.js hosting/VPS-এ deploy করুন; `.env` কখনো GitHub-এ দেবেন না।
- নিয়মিত `news.db` এবং `sessions.db` ব্যাকআপ রাখুন।
- production-এ rate limiting, CAPTCHA, image upload scanning, moderation policy, এবং contact/privacy pages যোগ করুন।
- কপি শনাক্তকরণ শতভাগ নিশ্চয়তা নয়: একই ঘটনা নিয়ে আলাদা প্রতিবেদনও মিলতে পারে, আবার শব্দ বদলে লেখা কপি এড়িয়ে যেতে পারে। তাই অ্যাডমিনের যাচাই জরুরি।
- ব্যবহারকারীর দেওয়া image URL-গুলো সরাসরি embed হয়; ভবিষ্যতে নিজস্ব নিরাপদ image upload ব্যবস্থা ব্যবহার করা উত্তম।

এই প্রকল্পটি চালানোর মতো starter website; এটি নিজে থেকে কোনো ডোমেইন/হোস্টিংয়ে প্রকাশিত হয়নি।
